বাণিয়াপাড়া নিউ যুব ইস্পোর্টশন ক্লাব — PWA সংস্করণ

এই ZIP-এ যা যোগ করা হয়েছে:
- Android Chrome থেকে Install App করার জন্য manifest ও service worker
- সদস্যের সাপ্তাহিক নির্ধারিত চাঁদা ফিল্ড
- সাপ্তাহিক চাঁদা নির্ধারণ ও জমার এন্ট্রির ভিত্তিতে আনুমানিক বকেয়া হিসাব
- বকেয়া সদস্যদের নাম, ফোন, বকেয়া ও SMS খসড়াসহ CSV তালিকা ডাউনলোড
- JSON ব্যাকআপ/রিস্টোর ও CSV রিপোর্ট আগের মতোই আছে

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- অনলাইন ক্লাউড ব্যাকআপ এখনও সংযুক্ত নয়। ডেটা এই ফোনের Chrome/browser localStorage-এ থাকে।
- CSV তালিকা SMS পাঠায় না; এটি শুধু SMS পাঠানোর জন্য তালিকা/খসড়া তৈরি করে।
- বকেয়ার হিসাব যোগদানের তারিখ থেকে প্রতি ৭ দিনে ১টি চাঁদা ধরে গণনা করে; যোগদানের দিনকেও প্রথম সপ্তাহ হিসেবে ধরে। ক্লাবের নিয়ম ভিন্ন হলে গণনার নিয়ম বদলাতে হবে।
- NID/পরিচয়পত্রের মতো সংবেদনশীল তথ্য রাখার আগে নিরাপদ লগইন, এনক্রিপশন ও সার্ভার-সাইড অনুমতি ব্যবস্থা যোগ করুন।
- এই অ্যাপটি Chrome Install App হিসেবে ইনস্টল করতে HTTPS-এ প্রকাশ করতে হবে। ZIP থেকে index.html সরাসরি খুললে Install App কাজ করবে না।

Android ফোনে ইনস্টল:
1. ZIP Extract করুন।
2. পুরো BaniaPara_Youth_Esports_Club_App ফোল্ডারটি HTTPS static hosting-এ আপলোড করুন (যেমন GitHub Pages বা Cloudflare Pages)।
3. প্রকাশিত ওয়েব ঠিকানাটি Android ফোনে Chrome দিয়ে খুলুন।
4. Chrome-এর menu (⋮) থেকে "Install app" বা "Add to Home screen" নির্বাচন করুন।
5. ইনস্টল করার পর আগে ছোট পরীক্ষামূলক তথ্য দিয়ে সদস্য, চাঁদা, খরচ, ব্যাকআপ ও SMS CSV পরীক্ষা করুন।

অনলাইন ক্লাউড ব্যাকআপের পরবর্তী ধাপ:
- Firebase/Supabase-এর মতো backend নির্বাচন, নিরাপদ sign-in ও database/storage rules সেট করা প্রয়োজন।
- সেটআপের জন্য project credentials/config দরকার হবে; সেটি না থাকায় এই ZIP-এ cloud sync ভান করে যোগ করা হয়নি।
- আপাতত Reports & Backup থেকে নিয়মিত JSON ব্যাকআপ ডাউনলোড করে নিরাপদ জায়গায় রাখুন।
